# HF Chronologische Startseite

Tijdelijke overbrugging voor FKB Pro: stuurt kaal `/` of `/latest` door
naar `/latest?order=created`, zodat de startpagina altijd de nieuwste
berichten toont in plaats van de laatst-actieve (geen bumping).

Expliciete sorteringen (bijv. `/latest?order=activity`) blijven werken.

**Verwijderen zodra het Häkelfans-theme live gaat** — dat theme heeft
dezelfde redirect ingebouwd.
